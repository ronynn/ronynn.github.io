🌐 ronynn's landing page

Recently rewritten using Astro 7, not out of necessity but out of my curiosity to get into this rust powered toolkit, it sure is fast. The site is around 11kb at the moment.

The main focus is the Webgl powered landing page! This used to be vanta+threejs globe but I learned a whole lot of math and poked different repositories, google search and friends and with all the collective knowledge managed to get the same globe with no dependencies.

With this project specifically, applying webgl stuff with pseudocode was a time saver.(or perhaps the only way, idk try bugging some AI with any of the vantajs themes lets see if it can remake it by itself! ... it can't yet)

For some of the matrix calculations, I was initially using numpy-ts, though 100kb js addition wasn't going to solve anything, used a small AI written matrix library implementation.

The homepage sort of represents global connectivity and my creativity in a sense connecting to the global world. The dynamic globe at its center symbolizes the unity of ideas from every corner of the world, and it being a corner for me to show my projects.
