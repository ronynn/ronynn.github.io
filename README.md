🌐 ronynn's landing page



Welcome to my webgl powered landing page! This used to be vanta+threejs globe but I learned a whole lot of math and poked different LLMs with all my knowledge and managed to get the same globe with no dependencies.

LLMs are just not quite there yet when it comes to anything non-trivial, atleast judging by all the free llms I have access to. Philosophy wise, I still think, that a reiteration of software making isn't a bad idea. We no longer have to rely on slower code or dependencies just because they are easy to learn or maintain, things should be faster. On the other hand, you can't rely on AI for your architecture, your perspective should be available, code it writes should be terse enough that it never gets out of hand/context, while dependency free enough that it stays fast.

With this project specifically, applying webgl stuff with pseudocode was a time saver.(or perhaps the only way, idk try bugging some ai with any of the vantajs themes lets see if it can remake it by itself!)

For some of the matrix calculations, I was initially using numpy-ts, though 100kb js addition wasn't going to solve anything and AI wrote the matrix lib itself.

Though one might call me hypocrite, the latest version of this site uses backdrop filter blur that might make it slow on some devices, if it does noticeably, one line of code can undo it, though I like the frosty glass vibes, if only browsers made that performant enough.

This project is more than just a pretty design—it's a celebration of global connectivity and creativity in a sense. The dynamic globe at its center symbolizes the unity of ideas from every corner of the world. It’s a window into a universe where technology meets art, and a corner for me to show my projects.
